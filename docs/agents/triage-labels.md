# Triage Labels

| Rôle du skill     | Label du tracker  |
| ----------------- | ----------------- |
| `needs-triage`    | `needs-triage`    |
| `needs-info`      | `needs-info`      |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix`         | `wontfix`         |

Lorsqu’un skill mentionne un rôle de triage, utiliser le label correspondant.
